## 4-week template (3 days)

Rotates as you complete workouts (not calendar days):

1. Squat (or box squat), push-up (or knee), plank, glute bridge  
2. Lunge (or box squat if knees/pain), biceps curl if dumbbells, wall sit, bird dog  
3. Squat variant, push-up variant, dead bug, plank  

Blocked by injury:

- **Knees** — lunge, wall sit  
- **Back** — dead bug  
- **Shoulders** — push-up, knee push-up, plank, biceps curl
