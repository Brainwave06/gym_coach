# Team Responsibilities & Next Steps

This document outlines the division of labor across the project. Our app connects a local computer-vision (CV) AI coach with a mobile UI and a cloud backend. 

## 1. AI Team (This Repository)
**Role:** Build and maintain the core computer-vision exercise engine.
- **Current Status:** 
  - MediaPipe pose tracking, rep counting, and form correction logic are implemented (Squat, Push-up, Plank, etc.).
  - A local FastAPI bridge (`api.py`) is set up to receive video frames via WebSocket and return JSON form evaluations.
- **Next Steps:**
  - Refine form-checking thresholds based on user testing.
  - Add new exercises to the catalog.
  - Improve the dataset generation for training any future custom ML models.

## 2. Backend Team
**Role:** Build the permanent cloud infrastructure, database, and chatbot.
- **Current Status:** A starter `backend/` folder has been initialized with a basic FastAPI skeleton.
- **Next Steps (What you need to build):**
  - **Database & Auth:** Set up PostgreSQL/MongoDB to store user profiles and authentication.
  - **Data Sync:** Create REST endpoints to receive the `summary.json` and `coach_handoff.json` files generated by the AI after a workout.
  - **Chatbot / LLM:** Integrate an LLM (like OpenAI) to read the user's dataset/handoff files and generate personalized diet plans and tomorrow's workout suggestions.
  - **Deploy:** Host this API on a cloud provider (AWS/GCP/Render) so the Flutter app can reach it from anywhere.

## 3. Flutter & UI Team
**Role:** Build the mobile/web frontend that the athlete actually interacts with.
- **Next Steps (What you need to build):**
  - **Authentication Screens:** Login/Signup UI that talks to the Backend Team's server.
  - **Dashboard:** Fetch the user's daily workout plan and diet from the Backend and display it beautifully.
  - **Live Workout View (The magic):** 
    - Connect to the AI Team's local WebSocket (`ws://127.0.0.1:8000/stream/{exercise_id}`).
    - Stream the phone's camera frames (base64 JPEG) to this socket.
    - Read the returning JSON (`rep`, `stage`, `faults`) and display live UI cues (e.g., green/red overlays, rep counters) without running heavy ML on the phone itself.
  - **Post-Workout:** Show a summary screen and upload the final stats to the Backend.
